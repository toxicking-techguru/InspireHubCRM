# **App Name**: NexusCRM Leads

## Core Features:

- Lead & Activity Management: Centralized hub for managing leads, tracking their pipeline status, and logging all interactions in an immutable activity timeline.
- Role-Based Access & Dashboards: Secure role-based access control (Admin, Manager, Agent) with personalized dashboards displaying relevant performance metrics, targets, and team oversight.
- Automated Business Logic: System for real-time duplicate detection on lead creation, automatic identification of idle leads, and precise commission calculation upon deal closure.
- Agent Wallet & Withdrawals: Transparent tracking of agent commissions, total earnings, pending balances, and a process for requesting and managing withdrawals.
- Tier System & Progression: An automated system to evaluate agent performance against predefined criteria, facilitating tier upgrades and dynamic access to new products.
- Product Resource Center: Agents can access detailed product information and associated sales resources (scripts, documents, videos, FAQs) based on their assigned tier.
- Advanced Reporting & Analytics: Manager and Admin dashboards provide advanced insights into team performance, conversion rates, and upgrade candidates using charts and tables.

## Style Guidelines:

- Primary interactive color: Vibrant Indigo (#4F46E5) for key actions and active states, drawing from the user's requested accent color.
- Background color: A subtle, clean light blue-grey neutral (#F5F6F8) providing a professional and unobtrusive canvas for content.
- Accent color: A soft, complementary sky blue (#A4D2EA) to add visual differentiation and highlight secondary elements.
- Body and headline font: 'Inter' (sans-serif) for its modern, neutral, and highly readable characteristics suitable for data-dense applications.
- Code font: 'Source Code Pro' (monospace sans-serif) for presenting any technical content or product scripts in a clear, consistent manner.
- Utilitarian line icons with simple, direct representations for navigation, actions, and status indicators, maintaining a compact aesthetic.
- Dense, professional layout prioritizing information and functional elements. Key structural features include a collapsible sidebar, tight padding (p-3/p-4) on cards and tables, and compact data typography (13-14px for data, 15-16px for headings).
- Subtle and efficient animations primarily for indicating state changes, loading processes, and immediate feedback on user interactions, ensuring a swift and responsive experience.
